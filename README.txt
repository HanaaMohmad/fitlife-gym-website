FitLife Gym Website
====================

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern browser.

Features:
- Responsive design for desktop and mobile
- Gym class cards with fitness photography
- About, trainers, and contact sections
- Mobile navigation menu
- Join form modal with front-end confirmation

Images and font are loaded from external Unsplash and Google Fonts URLs, so an internet connection is needed for those assets.
The join form is a front-end demo only; connect it to an email service or backend to receive real submissions.
